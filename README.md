# wifidar

Wi-Fi as a robot sensor, with Foxglove as two-way mission control.

> Work in progress.

## Project layout

| Folder | Contents |
|---|---|
| `firmware/` | ESP32 firmware (Arduino, C++) |
| `bridge/` | Python bridge between the ESP32 and Foxglove |
| `extension/` | Signal Hunter, a custom Foxglove panel (TypeScript, React) |
| `foxglove/` | Exported Foxglove layout |
| `recordings/` | Sample MCAP recording |
| `docs/` | Devlog, write-up, and images |
